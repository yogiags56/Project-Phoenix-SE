# Phoenix Firmware Compatibility Mapper

Conservative comparison of Phoenix JSON reports. Requires Python 3.10+ and uses only the standard library.

## Prepare report directories

Create two directories, one for the target iPhone SE (n69) evidence and one for a donor device. Put JSON reports generated by Phoenix tools into the corresponding directory. Keep each side's reports separate.

Example layout:

    reports/
      target-n69/
        ipsw.json
        macho.json
        kernel-collection.json
        kexts.json
      donor-device/
        ipsw.json
        macho.json
        kernel-collection.json
        kexts.json

The input directories may contain any combination of Phoenix JSON reports. The mapper records source report names and hashes.

## Usage

    python3 tools/phoenix-compat/phoenix_compat.py --target reports/target-n69 --donor reports/donor-device --out reports/compatibility.json

Run tests:

    python -m unittest discover -s tools/phoenix-compat/tests -v

## Status semantics

- `Potential`: shared CPU architecture values or component identifiers provide a lead for deeper research. Not a compatibility verdict.
- `Incompatible`: both sides declare CPU architecture values and their architecture sets are disjoint. This is a binary-architecture conflict only.
- `Unknown`: the reports do not provide enough comparable positive evidence.

Matching product type strings and version strings are shown as context only. They do not change the status.

## Important limitations

This is an evidence organizer, not a firmware compatibility oracle. It does not prove ABI or kernel API compatibility, driver loadability, device-tree correctness, SEP/baseband compatibility, Cryptex support, code-signing acceptance, or userspace operation. A shared Bundle ID does not prove matching binary contents. The tool does not inspect raw firmware and never modifies, signs, executes or restores it.

Use locally generated reports. Do not commit proprietary firmware, extracted kernel binaries, personal identifiers, or device-specific secrets.

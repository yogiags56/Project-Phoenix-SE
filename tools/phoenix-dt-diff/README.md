# Phoenix Device Tree Comparator

Read-only structural comparison of two JSON reports generated by Phoenix FDT Analyzer. Requires Python 3.10+ and only the standard library.

## Usage

First analyze each raw standard FDT/DTB blob separately:

    python3 tools/phoenix-fdt/phoenix_fdt.py target.dtb --out reports/target-fdt.json
    python3 tools/phoenix-fdt/phoenix_fdt.py donor.dtb --out reports/donor-fdt.json

Then compare the reports:

    python3 tools/phoenix-dt-diff/phoenix_dt_diff.py --target reports/target-fdt.json --donor reports/donor-fdt.json --out reports/device-tree-diff.json

Run tests:

    python -m unittest discover -s tools/phoenix-dt-diff/tests -v

## What is compared

- Node paths present on each side, including nodes added or missing in the donor report.
- Properties added, removed or changed on nodes with matching paths.
- Shared `compatible` strings on matching paths.
- Critical-property differences for `reg`, `interrupts`, clocks, resets, power domains, GPIO, pinctrl, DMA ranges and related fields.
- Phandle definitions and changed values on matching node paths.
- SHA-256 hashes of the JSON reports and source FDT blobs.

Property comparisons use `raw_hex` when the FDT Analyzer provides it. This avoids treating heuristic string decoding as authoritative.

## Interpretation

A matching path or `compatible` string is only a structural clue. It does not prove the same silicon, driver, kernel API, wiring, interrupt routing, address translation, power sequence or boot compatibility. Node differences may also be expected between distinct products.

The tool reports differences; it does not assign a simplistic compatible/incompatible verdict.

## Limitations

Inputs must be Phoenix FDT Analyzer JSON reports. Raw DTB files, compressed data and Apple-specific wrappers are not parsed by this comparator. It does not resolve arbitrary phandle references or interpret provider-specific cell formats. No firmware is modified, patched, signed, executed or restored.

Use verified target and donor identities, exact firmware build records and independent source references when interpreting results. Do not commit proprietary firmware or extracted private device data.
